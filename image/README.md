# README screenshots

Captured on 2026-09-29 from the verified Release build of VJDeck 1.5.4,
whose source tree matches main commit `1c3ef9a117b48552e495292c14754797adcfa9c6`.

- `main.png`: a video deck with waveform, RATE fader and eight hot cue slots.
- `master-output.png`: Deck 1 and Deck 2 mixed with Crossfade.
- `playlist.png`: a demo M3U playlist containing video, PNG and PDF media.
- `search.png`: FastFind results from an indexed demo folder.

These are direct application-window captures, without compositing or retouching.
They were encoded as PNG without changing the decoded pixels.
The geometric videos, audio and still images were generated specifically for
these screenshots; they do not use third-party footage or the user's media library.
The app ran from a temporary copy with a separate bundle identifier and home
directory to isolate preferences, playlists and caches. Its bundle name and
display name were changed, URL scheme registration was removed, and the copy
was re-signed after those metadata changes. The production source and app
implementation were unchanged. The pointer and macOS capture indicator may
be visible as part of the original capture.
